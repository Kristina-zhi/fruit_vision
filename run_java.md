# Инструкция по запуску java сервера

1. Открыть проект через intelliJ
2. Перейти в главное меню (Alt + \)
3. Перейти в настройки проекта (Project Structure)
4. В качестве SDK выбрать ms-21 (при необходимости скачать). В качестве Language level выбрать 21 (Preview)
5. Нажать ПКМ на директорию java и отметить ее как Sources Root
6. Нажать ПКМ на директорию resources и отметить ее как Resources Root
7. Запустить FruitRecognitionApplication
8. Отредактировать созданный .env файл под свои данные
9. Запустить повторно
